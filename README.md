# Chopin Portfolio

Portfolio statis built with Astro. The current page keeps the existing visual
design while Astro handles the build and static output.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Three.js assets

Three.js is intentionally not loaded yet, so the initial page stays light. Put
future models, textures, and other static assets in `public/assets/three/`.
Add the Three.js scene as an Astro component or a client-side module when the
interactive scene is ready.
